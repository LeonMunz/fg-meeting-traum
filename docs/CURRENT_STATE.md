- **IMPLEMENTED** — `deploy/scripts/release.sh`: ONE fail-closed operator command for a FULL 40-character lowercase commit SHA that releases the production Compose topology (`deploy/compose.production.yaml`) to the exact published image pair by orchestrating the existing primitives only (the production Compose file, `deploy/scripts/postgres-backup.sh`, `GET /api/health/`).
